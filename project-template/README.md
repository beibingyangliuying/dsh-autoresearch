reports the path it used. Do not pre-create one to have somewhere to put something later.

## If this study already has its own document hierarchy

Then this scaffold is the wrong default for it: declare the real hierarchy in `AGENTS.md` §3 and delete
the files you did not use. **An existing convention outranks this layout.**

If a `research/` directory already exists, that directory is the layer root — a discipline writes
`research/references/…` there rather than starting a second tree at the study root. A study carrying both
a `research/` tree and root-level layers is not guessed at: the round stops and asks which one is the
study's.
