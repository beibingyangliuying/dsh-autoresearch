# `research/owner_actions.md` — what this round asks the owner to do

Written by a round that cannot finish its own work: a reference-library deletion, a judgement that is
only the owner's to make, a file only they can reach. **It is a request, never a record.** It grounds no
claim, it is not evidence, and it is rewritten as items close rather than appended to.

## Rules

- **One row per item**, and the action is one verb the owner can carry out: retire, write the
  replacement, delete in Zotero, decide.
- **A row without a reason is not a row.** The reason is what lets the owner decide without re-reading
  the paper.
- Where the round has already drafted the replacement, the row carries its path: the owner's act should
  not have to wait on another round.
- **Nothing here is done on the owner's behalf.** This preset performs no deletion in the reference
  library — the library's own API cannot put an item in the trash, so its answer to "delete these" is
  this list rather than a capability.
- Close a row by removing it, or by marking it `done <date>`. This file is not a log: the round-by-round
  record is `research/journal/`.
