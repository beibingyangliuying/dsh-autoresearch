# `research/literature/` — non-normative reconstruction notes

Produced by the `literature-recon` skill. One file per topic: `<topic>.md`.

## Conventions

- **Citation format**: TODO (default: title · authors · year · venue · DOI/arXiv id/URL).
- **Evidence grades are mandatory** on every source: `A` full text read · `B` abstract only ·
  `C` second-hand paraphrase.
- Every claim carries a source, or is marked `[exploratory]`.
- Contradicting evidence gets its own section. "None found" must state the search scope.
- Files here are **non-normative**: they never ground an experiment or a conclusion on their own.

## Required sections

1. `## Search question`
2. `## Summary of findings`
3. `## Evidence table`
4. `## Contradicting evidence`
5. `## Gaps and unknowns`
6. `## Non-normative declaration`
